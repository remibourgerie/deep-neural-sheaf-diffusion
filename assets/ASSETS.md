# Assets

Place the following files here before publishing:

| File | Source | Description |
|------|--------|-------------|
| `figure1_architecture.png` | Paper Figure 1 | Architecture illustration (sheaf diffusion diagram) |
| `figure2.png` | Generated by `plot_figure2.py` | Depth scaling at G5 |

To generate `figure2.png`:

```bash
python train_synthetic.py --config config_figure2.yaml --output results_figure2.csv
python plot_figure2.py --results results_figure2.csv --level 5 --output assets/figure2.png
```
